# Personal Finance Manager

CSC 221 Final Project

## Workflow

`main`
Official project releases. Do not push directly.

`develop`
Current integrated development version. Pull requests should normally
target this branch.

## Contributing

1. Pull the latest `develop`.
2. Create a branch for your work.
3. Make and test your changes.
4. Push your branch.
5. Open a pull request into `develop`.
6. Have another team member review the PR before merging.
